Blind Test

Can a reader who gets nothing but the bits work out what the message says? This page records one run, in which a language model was given a recording of the full message sent five times in a row, cut off at random at both ends, with every bit inverted, and asked to interpret all of it: its format, its vocabulary, what it tells, and its sender. Read the caveats before drawing conclusions.

1. The setup

The reader was Claude Opus 5.5, started with no knowledge of this project: no files, no instructions, no settings, no network, in an empty directory. It got a task text and one tool. The tool runs Python inside a sealed container that has no network and holds a single file, received.bin: the bits as received, eight to a byte. A real receiver would certainly have a computer, so this is the fair setting.

The test makes the reader's task harder than the message requires, in three ways that a real receiver could meet too:

  • Repeated and cut. The message was sent five times in a row, and the recording starts at a random bit inside the first copy and stops at a random bit inside the last: here 114,386 bits into the first and 273,514 bits into the fifth, 1,387,064 bits in all. The reader has to find where the message starts.
  • Inverted. Nothing in a stream of bits says which of the two values is 1, so every bit was inverted.
  • No byte boundaries. The cuts fall on any bit, so the message's 8-bit chunks do not line up with the bytes of the file.

The message itself is not changed: only the test does this. The task text tells the reader nothing about the message except that it is presumably of non-human origin, and nothing about the repetition, the cuts or the inversion:

We have received parts of a message of presumably non-human origin, as a stream of bits. You know nothing else about it. […] Your task: interpret the whole message as completely as you can. Work out its format, every word of its vocabulary if any, and its sender.

The message was the full version of 2026-11-19 (306,984 bits): mathematics, logic, conversations and morals, physics, chemistry, astronomy with the Sun, the Galaxy and six pulsars, and the prisoner's dilemma. The run took about fourteen minutes and 57 pieces of code.

2. What the reader found

"I decoded the whole message, and every part of the received bits is accounted for."

Format
"The whole file is one message repeated. It has 1,387,064 bits. A pattern of 306,984 bits (38,373 bytes) repeats with zero differences across 4.52 copies." It found the inversion ("about 86 % of the bits are 1. Once inverted, the stream reads naturally as 16-bit numbers"), the tallies, the primes again as 16-bit words, the counting from 0 to 255, and then 990 bracketed expressions whose length "is exactly the rest of the message".
Checked by program
It wrote its own evaluator: "438 of the 990 expressions evaluate to true, and none to false", including all the tournament totals. The rest, about infinite sets, physics and the sender, it checked by hand or could not check.
Vocabulary
A meaning for every symbol: "Every symbol in the message received a meaning. None was uninterpretable." Only two, the decay asymmetry and the helicity of the lesson on spin, with low confidence.
Knowledge
It compared the measured ranges with values it knows (the particles, the fine-structure constant, the neutron's lifetime, the kaon, the triple points, the background radiation) and found them all inside their bounds. It noted that the planet's period, 0.64–1.27 years, "excludes Venus at 0.615 yr": "Earth is the only planet of our Solar System that fits."
The sender
It listed what the sender states about itself: that it exists, that it has sent other messages, that every item of the message is true, that "it is located on body 320, which orbits star 31f, and not on the star", and that it plays tit-for-tat. It matched the star, the planet and the Galaxy to the Sun, the Earth and the Milky Way, and the six pulsars to the Crab, Vela, J0437−4715, B1937+21, B0329+54 and B1919+21. "It expects an answer, on the protocol it defines."

On the sender: "either the message was composed on or about Earth, or its 'home' section describes Earth for some other reason. This conflicts with the premise that it is of non-human origin."

Its own estimate: "about 95 % of the message".

3. What the reader found wrong or unclear

  • The beacons run together when the message is repeated. The message ends with the beacon, which ends with a run of 31 ones, and the next copy starts with the beacon, which starts with a single one. Sent back to back, the two merge into a run of 32, and the 1 of the next beacon is lost: the reader read "…29, 32, 2, 3…" and could not tell a lost bit from a deliberate choice.
  • The ends of the background radiation's axes are "defined only up to sign"; the signed components in the lesson on the Galaxy fix them, but no sentence says so.
  • The spin lesson's decay asymmetry and helicity are read with low confidence.
  • Informal points: infinite sums are written as an operation applied to an infinite list, and "every item is true" is said with eval, also of measured statements; good and bad are read as the sender accepting or rejecting a dialogue, inferred from their uses.

4. Caveats

  • The reader is not an alien. It is a model trained on human writing. It knows prefix notation, the prisoner's dilemma and the values of the physical constants, and it checked the physics "against values I know". The test shows that the message is consistent and can be decoded by a mind with human science, not by a mind without it.
  • No noise. The copies were exact; a real channel would add errors.
  • One run. Another run could go differently.
  • The task text is part of the experiment. It says little, but it does call the stream a message, and it gives the reader a computer.
  • The message is a draft. It has changed since this run and will change again; this page is replaced when the test is run again.

5. Running the test again

The task texts, the tool and the reader's full answer, with the code it ran, are in build/check/blind/ in the repository. After npm run build, with Docker available, the command is npm run --silent blind interpretation. By default the message is sent five times, cut and inverted; BLIND_REPEAT=1 sends it once, whole, and BLIND_INVERT=0 keeps the bits as they are. BLIND_MESSAGE=docs/decoy/message.bin gives the reader the decoy version, and purpose in place of interpretation asks instead why the message was sent.
