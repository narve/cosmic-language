The Core Message

A shorter message inside the full one: only the lessons that are needed to state the result of the game. It is the full message with whole lessons left out, and nothing rewritten.

What it is

The full message ends with a game between two players and the statement that the strategy which opens in peace and answers in kind ends with more than every other. The core is the shortest path to that statement: how the signal is read, arithmetic, truth values, lists, quantifiers, sequences, chance and if, and then the game. Real and complex numbers, quoting and eval, physics and chemistry are left out.

No core lesson uses a symbol that is introduced outside the core, so the core can be sent and read on its own. The numbers below are those the lessons have in the full message.

  • The core message itself: message.txt (readable, with symbol names), message.bits (the bits as text, one token per line), message.bin (the bits, packed into bytes) and message.bin.txt (message.bin as binary numbers, for viewing).
  • The full message, with all lessons.
