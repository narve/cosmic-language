Sentences in brackets

A sentence is an expression in brackets. The first element is the operator, and the rest are arguments, in what's called Lisp style. The brackets show what belongs together, so the receiver never has to guess how many arguments an operator takes.

Example: a simple sentence

"3 equals 3"
(= 3 3)

As bits, that's five tokens:

(  00000001 00000000
=  00000010 00000001
3  00000000 00000011
3  00000000 00000011
)  00000001 00000001

Example: nesting

A group can stand where a number stands:

"2 + 3 equals 5"
(= (+ 2 3) 5)
