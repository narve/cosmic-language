quoting

Until now, every sentence in the message has been asserted: written down, it claims to be true. The next lessons let the message mention a sentence without claiming it, take sentences apart like lists, and compute their values. The last of them is eval, the value of any expression, written in a few sentences of the message itself. This is the idea at the heart of Lisp, published by John McCarthy in 1960, and the first step towards a message that can describe itself.

New: quote and type. (quote S) is the expression S itself, not its value: nothing inside it is computed or claimed. A quoted expression in brackets is a list of its parts, so everything from the lesson on lists works on it.

(= (quote (+ 2 3)) (list (quote +) 2 3))
(= (length (quote (+ 2 3))) 3)
(= (item (quote (+ 2 3)) 1) (quote +))  (= (item (quote (+ 2 3)) 2) 2)  (= (item (quote (+ 2 3)) 3) 3)

; a symbol can be quoted on its own
(= (quote +) (quote +))  (≠ (quote +) (quote ×))

; numbers are their own quotes
(= (quote 5) 5)

; an expression is not its value, and two expressions with the same value are still different
(= (+ 2 3) 5)  (≠ (quote (+ 2 3)) 5)
(= (+ 2 3) (+ 3 2))  (≠ (quote (+ 2 3)) (quote (+ 3 2)))

; quoted expressions can be nested
(= (item (quote (= (+ 2 3) 5)) 2) (quote (+ 2 3)))
(= (item (quote (quote 7)) 1) (quote quote))

Because a quoted sentence is only mentioned, it may be false. This is the first time a false sentence appears in the message, and it is never asserted:

; the sentence "2 = 3", taken apart
(= (length (quote (= 2 3))) 3)
(= (item (quote (= 2 3)) 1) (quote =))
(= (item (quote (= 2 3)) 3) 3)
(≠ (quote (= 2 3)) (quote (= 3 3)))

type tells what kind of thing a part of an expression is. Its values are the token types the message has used from the start, the first chunk of every token: 0 for a number, 2 for an operator, 3 for a constant, and so on. A list in brackets has type 1, the type of the brackets. Later lessons bring new kinds of token (particles, elements, dimensions, physical constants, molecules), and each states the type of its tokens in the same way.

(= (type 5) 0)  (= (type (quote (+ 2 3))) 1)  (= (type (quote +)) 2)  (= (type (quote true)) 3)
(= (type (quote u)) 4)  (= (type (list 1 2)) 1)
; an operator in a quoted expression is a symbol like any other
(= (type (item (quote (+ 2 3)) 1)) 2)  (= (type (item (quote (+ 2 3)) 2)) 0)

Inside a quote, u is just a symbol of type 4, not a variable standing for a number.
