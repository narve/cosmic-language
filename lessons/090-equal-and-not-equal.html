equal and not equal

New: brackets, and the first two symbols, = and ≠. This is where the message starts to make statements.

Sentences in brackets

After the calibration, two new kinds of token appear. Tokens of type 1 have only two values, 0 and 1, and they always come in pairs around other tokens: they are brackets, ( for 0 and ) for 1. A token of type 2 is a symbol. In this lesson, every pair of brackets holds a symbol followed by numbers. The first group, token by token:

(  00000001 00000000   type 1, value 0: open
=  00000010 00000001   type 2, value 1: the first symbol
1  00000000 00000001   type 0: the number 1
1  00000000 00000001   type 0: the number 1
)  00000001 00000001   type 1, value 1: close

Such a group is a sentence: (= 1 1). The symbol right after the opening bracket is the operator, and the rest are its arguments, in what's called Lisp style. The brackets show where each sentence starts and ends, so the receiver never has to guess how many arguments an operator takes. Every sentence the message asserts is true; what each operator means, the receiver works out from many sentences that use it.

Equal

The first operator is =. In every sentence its two arguments are the same number, so the receiver can guess what it means: the two are equal. The numbers are the primes the receiver already knows from the beacon and the calibration, and then the smallest and the largest number a chunk can hold. Two or three sentences would not be enough to guess from, and one of them might arrive damaged, so the message gives more examples than seem necessary, here and in every later lesson.

; each number equals itself: first the primes of the beacon
(= 1 1)
(= 2 2)
(= 3 3)
(= 5 5)
(= 7 7)
(= 11 11)
(= 13 13)
(= 17 17)

(= 19 19)
(= 23 23)
(= 29 29)
(= 31 31)

; then the smallest and the largest number of a chunk
(= 0 0)
(= 255 255)

Not equal

Then comes a second symbol, ≠, always between two different numbers. Since = only ever joined a number to itself, ≠ must mean the opposite: the two are not equal. Sentences with both, side by side, show the contrast.

; two different numbers are not equal
(≠ 0 1)
(≠ 1 0)
(≠ 2 5)
(≠ 7 3)
(≠ 254 255)

; mixed, to show the contrast
(= 4 4)
(≠ 4 5)
(= 9 9)
(≠ 9 6)

; = can compare more than two: all are equal
(= 3 3 3)
(= 7 7 7 7)
(= 0 0 0 0 0)

= takes two or more arguments and means that all of them are equal. ≠ takes exactly two: with more, it would be unclear whether it means "all different" or "not all equal".
