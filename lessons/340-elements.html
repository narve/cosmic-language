elements

New: the elements (a new type) and the domain elements. count from the lesson on lists now tells how many of a particle an atom contains. The value of an element token is its number of protons, so hydrogen is element 1, helium element 2, and so on. This is a definition, not a measurement, so it is not marked observed.

; protons: the number that defines each element
(= (count proton hydrogen) 1)  (= (count proton helium) 2)
(= (count proton carbon) 6)  (= (count proton oxygen) 8)
; electrons: the same numbers
(= (count electron hydrogen) 1)  (= (count electron helium) 2)
(= (count electron carbon) 6)  (= (count electron oxygen) 8)

; the four elements in order of their protons
(< (count proton hydrogen) (count proton helium) (count proton carbon) (count proton oxygen))
; every element has at least one proton
(∀ u elements (≥ (count proton u) 1))

; atoms are neutral: as many electrons as protons, so no charge in total
(∀ u elements (= (count electron u) (count proton u)))
(observed (∀ u elements (= (charge u) 0)))

; a hydrogen atom weighs only a little more than its proton: the electron adds very little
(observed (< 1 (÷ (mass hydrogen) (mass proton)) (÷ 101 100)))

Neutron counts are left out here: atoms of the same element can have different numbers of neutrons. The next lesson deals with that.
