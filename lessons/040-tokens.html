Tokens: what kind of thing?

A token is two numbers in a row. The first says what kind of thing this is (the type), and the second is the thing itself (the value).

TypeMeaningValue
0numberthe number itself
1structure0 = open bracket, 1 = close bracket
2symbolwhich symbol (=, +, …)

Example

type             value
00000000 00000011   number 3
00000010 00000001   symbol no. 1 (=)
00000001 00000000   structure: (
00000001 00000001   structure: )

In the first part of the message nearly every type chunk is 00000000, 00000001 or 00000010. That makes the 16-bit period between tokens easy to spot. More types are introduced later, as lessons in the message itself.

From here on the tutorial writes tokens in short form: 3 is a number, = is a symbol, and ( ) are brackets.
