light and c

New: the particle photon, the domain photons (all individual photons), the functions speed, wavelength and frequency, and the constant c, a new type for physical constants.

; a photon has no mass and no charge
(observed (= (mass photon) 0))  (observed (= (charge photon) 0))

; every photon has the same speed, c
(observed (∀ u photons (= (speed u) c)))
(observed (= (speed photon) c))
; the dimension of a speed: length ÷ time
(∀ u photons (= (dim (speed u)) (÷ L T)))
(= (dim c) (÷ L T))

; for every photon, wavelength × frequency = c
(observed (∀ u photons (= (× (wavelength u) (frequency u)) c)))
; a frequency is a number per time, a wavelength is a length
(∀ u photons (= (dim (frequency u)) (÷ 1 T)))
(∀ u photons (= (dim (wavelength u)) L))

; the frequency of a photon is never 0, so the law can be turned around: wavelength = c ÷ frequency
(observed (∀ u photons (> (frequency u) 0)))
(observed (∀ u photons (= (wavelength u) (÷ c (frequency u)))))
