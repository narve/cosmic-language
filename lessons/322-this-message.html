this message

Until now the message has spoken about numbers, logic and the world. Now it speaks about itself. New: message, this message, as the list of everything sent in tokens after the beacon at its start, to its end: numbers and sentences, in order. The beacon itself, written in runs of 1s, is not an item: the list starts with the primes sent again as tokens, and the sentences follow them. What is in it can be counted with count, and a sentence is named with quote, so that it is mentioned and not claimed.


; the message starts with the numbers of the calibration: 1, 2, 3, 5
; …
(= (item message 1) 1)
(= (item message 2) 2)
(= (item message 4) 5)

; the twelfth is 31, the last prime of the calibration, and the
; thirteenth is the first sentence: the beacon in 1s is not counted
(= (item message 12) 31)
(= (item message 13) (quote (= 1 1)))

; these sentences are in the message, once each
(= (count (quote (= 1 1)) message) 1)
(= (count (quote (= 3 3)) message) 1)
(= (count (quote (≠ 0 1)) message) 1)
; this one is in it twice
(= (count (quote (= 5 5)) message) 2)

; these are not in the message, and they are false
(= (count (quote (= 2 3)) message) 0)
(= (count (quote (< 3 2)) message) 0)
(= (count (quote (= (+ 2 2) 5)) message) 0)

; these are not in the message either, although they are true: being
; in it and being true are different things
(= (count (quote (= 6 6)) message) 0)
(= (count (quote (< 5 6)) message) 0)
(= (count (quote (= (+ 3 3) 6)) message) 0)
