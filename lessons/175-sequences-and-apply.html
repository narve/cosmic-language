sequences and apply

Two tools that build on lists: sequences, which follow a rule for as long as needed, and chance, which is a proportion of a list.

New: apply, which gives the items of a list to an operation as its arguments, and sequence, which builds a list from a rule.

; apply + to the items of a list: their sum
(= (apply + (list 1 2)) 3)  (= (apply + (list 1 2 3)) 6)

; the same as writing the items as arguments
(= (apply + (list 1 2 3 4)) (+ 1 2 3 4) 10)

; apply × gives the product
(= (apply × (list 2 3 4)) 24)

; apply < says that the items are in increasing order
(apply < (list 1 5 9))

sequence has the same form as the quantifiers: a variable, the values it runs through, and a rule for each item. Over a list, it gives a list:

; the rule "u itself" gives the same list; the rule "u + 1" adds 1 to every item
(= (sequence u (list 1 2 3) u) (list 1 2 3))  (= (sequence u (list 1 2 3) (+ u 1)) (list 2 3 4))

; the rule "u × u" gives the squares
(= (sequence u (list 1 2 3 4) (× u u)) (list 1 4 9 16))
; a sequence is a list, so apply works on it
(= (apply + (sequence u (list 1 2 3) u)) 6)

Over ℕ it gives an infinite sequence, which continues without end by the same rule. Its first item is the one for 0:

; the natural numbers themselves: the first item is 0, the fifth is 4
(= (item (sequence u ℕ u) 1) 0)  (= (item (sequence u ℕ u) 5) 4)

; the squares: the first item is 0 × 0
(= (item (sequence u ℕ (× u u)) 1) 0)
