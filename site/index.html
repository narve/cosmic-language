We come in peace — in the Cosmic Language

A message that explains itself: it starts from bare bits and builds up, one lesson at a time, through mathematics and physics, so that a receiver who shares nothing with us but math, logic and physics can read it.

Intro

I've always been fascinated by aliens, and how to communicate with them. This is my attempt to build a self-describing message, starting from scratch, with no shared assumptions.

There are several versions of this message:

  • A minimal version, trying only to say "We come in peace".
  • A full version, explaining more advanced math and physics and chemistry, and using that to describe and place the Sun, the Earth and the humans.
  • A "cautious" version, the same as the full version, but leaving out anything that can link this message to us. (Dark forest!)
  • A decoy version, similar to the full version but swapping the actual truth with a hopefully plausible alternative civilization, living on a moon of a giant planet that circles a pair of stars (Kepler-1647).

The full version is also used to test whether the most alien intelligences we have access to, modern LLMs, can understand the message without any instructions. The results of these experiments are described on the blind test page. (Spoiler: They can!)

The message is presented as a set of annotated and reader-friendly HTML-pages, with options to show the message both as the "source" (the way we write it), and as the bits that are actually sent.

Impatient?

If you just want to read the messages, I suggest you start with the minimal version. It is a bit heavy on math and logic, so be warned — I find it hard to write a self-describing message without using concepts that non-programmers might find complicated.

After that, go to the full version to get the advanced math, physics, chemistry, astronomy, and finally to the Sun, the Earth and the humans. (Or try the decoy version :D)

A very high-level description

I start the message with a list of prime numbers (including 1!), just to make it clear that this is an artificial message, not noise. This is in unary notation, just a list of 1s: 01011011101111101111111, etc.

Then I repeat the prime numbers, but this time in the standard binary notation I use throughout the message.

The notation uses S-expressions, like Lisp, and initially uses math to define various terms.

I then build on this math to introduce actors, strategies, morals etc., so that we finally can say:

We come in peace

  • I have several build-time checks and verifications, but there can definitely be errors, especially in the physics part.

Documents

  • Specification: the exact rules of the format.
  • Vocabulary: every type and symbol, with its meaning, the lesson that introduces it and the lessons that use it.
  • Each version on one page, all its lessons in the order of the message:
    • Full
    • Cautious
    • Minimal
    • Decoy
  • Versions: the four versions of the message, what each leaves out, and their message files.
  • Decoy: the decoy version, Kepler-1647, and how its numbers were worked out and checked.
  • Topics: the lessons grouped by topic, with an introduction to each.
  • Previous work: earlier messages to the stars and what we learn from them.
  • Twenty aliens: readers imagined by fiction, from the almost human to the hardly a being at all, and what the message would mean to each.
  • Blind test: what a reader made of the message when it got nothing but the bits (the latest run).
