New: rest, a list without its first item, and if, which picks one of two values. With item, rest lets a list be taken apart one item at a time: the first item, then the rest. 


; rest drops the first item; the rest of a list of one is empty
(= (rest (list 4 7 9)) (list 7 9))
(= (rest (list 7 9)) (list 9))
(= (rest (list 9)) (list))

; the rest is one item shorter
(= (length (rest (list 4 7 9))) 2)
; the rest of a list of two is a list of its second item
(∀ u ℕ (∀ v ℕ (= (rest (list u v)) (list v))))
; the second item of the rest is the third item of the list
(∀ u ℕ (∀ v ℕ (∀ w ℕ
  (= (item (rest (list u v w)) 2) (item (list u v w) 3)))))

rest is never applied to an empty list.

(if u v w) is v when u is true, and w when u is false: 


; if true, the first value; if false, the second
(= (if true 1 2) 1)
(= (if false 1 2) 2)

; the condition can be any relation: 2 < 3 holds, so 5
(= (if (< 2 3) 5 7) 5)
(= (if (not (< 2 3)) 5 7) 7)
