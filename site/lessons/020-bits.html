bits and the beacon

The message is a sequence of bits. Both 0 and 1 are active signals (for example two different frequencies), so a 0 can never be confused with silence. The message starts when the signal starts.

The first thing the receiver meets is the beacon: the prime numbers written as runs of 1s, separated by a single 0. In this message, 1 counts as a prime, so the beacon starts with a single 1: the smallest possible count.

Example

1 0 11 0 111 0 11111 0 1111111 0 11111111111 0 1111111111111 0 …
1   2    3     5       7         11            13

No natural process is known to send the prime numbers in order, so the beacon says that this is artificial. It also teaches the receiver the first convention: a run of 1s means a count.

The whole beacon, as it is sent: 174 bits. It starts with a single 0, and every run ends with one, the last one too, so each run of 1s has a 0 on both sides, whatever was sent before the beacon.


; a 0, then 1, 2, 3, 5 and 7
0 1 0 11 0 111 0 11111 0 1111111 0
; 11, 13 and 17
11111111111 0 1111111111111 0 11111111111111111 0
; 19 and 23
1111111111111111111 0 11111111111111111111111 0
; 29 and 31
11111111111111111111111111111 0 1111111111111111111111111111111 0

The beacon is sent only at the start: there is no end marker. Sent once, the message ends when the signal stops. Sent again and again, each copy starts with the beacon, so the beacon also marks where one copy ends and the next begins.
