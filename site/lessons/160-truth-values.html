truth values

Until now every sentence has been an assertion. This lesson shows that a relation also has a value: true or false.

Nothing false is written. Every relation in the message still holds, and false only appears as the value of an expression built with not, and or or.

Relations have the value true


; two new constants: each equals itself, and they differ
(= true true)
(= false false)
(≠ true false)
(≠ false true)

; a relation that holds has the value true
(= (= 2 2) true)
(= (< 1 2) true)
(= (≠ 3 4) true)
(= (> 5 1 0) true)

; all three are equal: true, and two relations that hold
(= true (= 7 7) (< 0 255))

; false is something other than true
(≠ true false)

not


; not turns true into false and false into true
(= (not true) false)
(= (not false) true)

; not of a relation that holds is false
(= (not (= 2 2)) false)
(= (not (< 1 2)) false)

; applying it twice gives the original, like neg
(= (not (not true)) true)

and and or

Both are associative, so they take two or more arguments.


; and is true only when both are true
(= (and true true) true)
(= (and true false) false)

(= (and false true) false)
(= (and false false) false)

; or is true when at least one is true
(= (or true true) true)
(= (or true false) true)

(= (or false true) true)
(= (or false false) false)

; with three arguments: all of them, or at least one of them
(= (and true true false) false)
(= (or false false true) true)

; a chain is an and of its steps
(= (and (< 1 2) (< 2 3)) (< 1 2 3))
; a true part and a false part: together false
(= (and (= 2 2) (not (= 3 3))) false)
; not of an and is the or of the nots
(= (not (and true false)) (or (not true) (not false)))

Between truth values, = means "equivalent", so no separate symbol is needed for that.
