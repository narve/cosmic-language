elements

count from the lesson on lists now tells how many of a particle an atom contains. The value of an element token is its number of protons, so hydrogen is element 1, helium element 2, and so on. Here are the first 36, from hydrogen to krypton, without a gap; later lessons use some of them, and the rest are here so that the list is whole. This list is a definition, not a measurement, so it is not marked observed; the measured facts at the end of the lesson are.

; every element has at least one proton
(∀ u elements (≥ (count proton u) 1))

; atoms are neutral: as many electrons as protons, so no charge
; in total
(∀ u elements (= (count electron u) (count proton u)))
(observed (∀ u elements (= (charge u) 0)))
