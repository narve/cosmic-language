subtraction and negative numbers

To begin with, only differences that stay at or above zero: 


; taking away 1 gives the number before
(= (− 1 1) 0)
(= (− 2 1) 1)
(= (− 4 1) 3)

; other differences; the last one is 256 − 1 = 255
(= (− 5 3) 2)
(= (− 9 0) 9)
(= (− 7 7) 0)
(= (− (num 1 0) 1) 255)

; − undoes +: (5 − 3) + 3 = 5
(= (+ (− 5 3) 3) 5)

Then the difference goes below zero, and a new symbol, neg, is needed for the result: 


; counting down past 0: 1, 0, then neg 1, neg 2, neg 3
(= (− 2 1) 1)
(= (− 1 1) 0)
(= (− 0 1) (neg 1))
(= (− 0 2) (neg 2))
(= (− 0 3) (neg 3))

; taking away more than there is
(= (− 3 5) (neg 2))
(= (− 4 9) (neg 5))
(= (− 2 9) (neg 7))

; a number and its neg add up to 0
(= (+ (neg 2) 2) 0)
(= (+ 5 (neg 5)) 0)

; neg 0 is 0, and neg twice gives the number back
(= (neg 0) 0)
(= (neg (neg 4)) 4)

; negative numbers are below 0, and a larger neg is further below
(< (neg 3) (neg 1))
(< (neg 1) 0)
(> 0 (neg 5))

; the sign rules of ×: one neg gives a neg, two give a positive
; number
(= (× (neg 2) 3) (neg 6))
(= (× (neg 2) (neg 3)) 6)

Strictly speaking, − is not needed once neg exists: (− u v) is the same as (+ u (neg v)). It is included anyway, because the message values clarity over a minimal vocabulary. Negation, neg, is deliberately a separate symbol from subtraction, −. A symbol never changes meaning with the number of arguments it gets. Human math notation is sometimes confusing and convention-based, not something we want in this message!
