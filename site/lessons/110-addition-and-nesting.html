addition and nesting

This is the first lesson where groups appear inside groups: a group can stand where a number stands. (+ 2 3) is the number 5, so (= (+ 2 3) 5) says that 2 + 3 equals 5. 


; adding 1 gives the next number
(= (+ 0 1) 1)
(= (+ 1 1) 2)
(= (+ 2 1) 3)
(= (+ 3 1) 4)
(= (+ 4 1) 5)

; other sums; the order of the two numbers does not matter
(= (+ 0 0) 0)
(= (+ 3 4) 7)
(= (+ 2 3) 5)
(= (+ 3 2) 5)

; adding 0 changes nothing
(= (+ 1 0) 1)
(= (+ 0 7) 7)

; up to the largest number in a chunk
(= (+ 254 1) 255)

; a sum inside other relations: 2 + 2 is less than 5, and not equal
; to 5
(< (+ 2 2) 5)
(≠ (+ 2 2) 5)

; + adds any number of terms
(= (+ 1 2 3) 6)
(= (+ 1 1 1 1) 4)
(= (+ 2 0 3 0) 5)

; grouping does not matter: 1 + 2 + 3 = (1 + 2) + 3 = 1 + (2 + 3)
(= (+ 1 2 3) (+ (+ 1 2) 3) (+ 1 (+ 2 3)))
